A blog made up entirely of apologies for not posting and promises to do more is not, typically, interesting. But a recurring and entirely unsuccessful *professional* New Year's Resolution has been to blog more.
Success breeds success though right? So this post will tick that one off, and then I can move onto the vaguer and more useful ones - read more journal articles etc. 

THe is also the first post in the LLM era, which makes me think about relevance, need. Who is this for? Will it be read only by AI? 

You may ask if it was written by AI - in this case, no, just very bad spelling in a Markdown file. But I can't promise that will never be the case, so will endeavour to tag when and how it is used in any future posts. 

Overall, I'm going to try to bring this site up to date, both the blog and overall website. For exmaple: the homepage has been neglected - [Side Projects]()https://lonsbio.com.au/sideprojects/ menu item has for the longest time returned:

```
Page Not Found
Sorry, but the page you were trying to view does not exist — perhaps you can try searching for it below.
```

which for those who know me well is giving entirely the wrong impression. So that needs to be updated, even if only for the most public and cherished of my side projects [😎](https://github.com/fastqe/fastqe) while the alomst-done ones remain in stealth mode. 

I'm not even sure if the GitHub actions will still work. But you have to start somewhere, which is... here.
